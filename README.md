# 横浜コミュニティデザイン・ラボ ナレッジコモンズ

> **Yokohama Community Design Lab — Knowledge Commons**

特定非営利活動法人 横浜コミュニティデザイン・ラボ（2003年設立、横浜市中区）が、22年間の実践から蓄積したナレッジをオープンに共有するリポジトリです。

「市民活動×テクノロジー×ローカル」の交差点で活動してきた知恵を、同じ課題を抱えるNPO・市民団体・地域組織のコモンズとして提供します。

---

## このリポジトリでできること

- **ノウハウを読む**：まちづくり・コミュニティデザイン・DMO・ソーシャルビジネスの実践知
- **テンプレートを使う**：企画書・補助金申請・ワークショップ設計の雛形
- **活動の軌跡をたどる**：プロジェクト記録・年表

---

## フォルダ構成

```
yokohama-cdlab/
├── README.md                  # このファイル
├── knowledge/                 # 実践ノウハウ（テーマ別）
│   └── cowork-obsidian-npo.md # AI×Obsidianでナレッジ管理を実践した話（初稿）
├── projects/                  # プロジェクト記録（追加予定）
├── history/                   # 活動年表（追加予定）

```
